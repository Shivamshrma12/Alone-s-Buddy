# Components (`/components`)

This directory houses modular UI components for Alones Buddy.

## Design Architecture
- **Single Responsive Codebase**: All components adapt responsively across viewport breakpoints.
- **Desktop View**: Futuristic navigation command center with multi-panel safety telemetry, environmental assessment, and agent reasoning logs.
- **Mobile View**: Streamlined map-first pedestrian navigation interface optimized for one-handed operation and high-contrast safety visibility.
- **Micro-Interactions**: Framer Motion transitions and reactive safety alerts.
