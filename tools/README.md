# Tools (`/tools`)

This directory contains executable tool definitions and implementations callable by the autonomous navigation agent.

## Core Tool Categories
- **Routing & Rerouting**: Safe-path calculation, alternative route generation favoring well-lit, populated paths.
- **Environmental Assessment**: Lighting index, incident reports, open emergency services / commercial hubs.
- **Safety Beacon & Alerts**: Notification triggers, emergency contact pinging, check-in prompts.
- **Telemetry Ingestion**: Processing pedestrian movement cadence, deviation detection, and geofencing.
