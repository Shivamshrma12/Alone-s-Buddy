# Supabase (`/supabase`)

This directory contains database schemas, migrations, configuration, and client interfaces for Supabase.

## Scope
- Database schema definitions (users, active journeys, safety waypoints, hazard reports).
- Migration scripts and seed data.
- Row-Level Security (RLS) policies for user privacy and telemetry safety.
- Realtime subscriptions for live journey synchronization across views.
